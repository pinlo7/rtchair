# 荣泰 RT7709S 按摩椅 · Home Assistant 集成

通过路由器上的「本地假阿里云 broker」离线控制按摩椅（不依赖荣泰云）。

## 安装

把 `custom_components/rtchair` 整个目录复制到 HA 配置目录的 `custom_components/` 下，
重启 Home Assistant，然后在「设置 → 设备与服务 → 添加集成」里搜「荣泰按摩椅」，
填本地 broker 地址（默认 `http://192.168.1.1:8891`）。

> 前置：先运行本仓库的 `tools/offline_on.sh` 开启离线模式。

## 实体

- 开关：电源、暂停、零重力、全身/臂肩/背腰/臀部/小腿气囊
- 下拉：自动程序（12 个）、按摩手法、按摩时长、机芯部位
- 数值：3D 力度、机芯速度、气囊力度、背部加热、小腿加热、脚底滚轮
- 传感器：状态、当前程序、已运行时长
- 按钮：运行预设程序（久坐救星 30 分钟 / 肩颈重点 20 分钟 / 睡前安神 20 分钟）
