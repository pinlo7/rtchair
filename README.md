# rtchair — 荣泰 RT7709S 按摩椅 · 离线控制 & Home Assistant 集成

> 把荣泰 RT7709S 按摩椅从「只能连官方云」变成 **完全本地控制**，并接入 Home Assistant。
> 支持自定义按摩程序（时间线/参数编排）、离线模式、一键预设、摇椅模拟。

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

## 这是什么

逆向了荣泰 RT7709S 按摩椅的通信协议后，实现了：

| 能力 | 说明 |
|---|---|
| **本地控制** | 路由器上跑一个「假阿里云」MQTT broker，椅子以为连的是官方云，实际全在家里的局域网 |
| **离线可用** | 不依赖外网、不需要荣泰账号、不需要 token |
| **Home Assistant** | 自定义集成（HACS 可装），32 个实体 + 自带仪表盘 |
| **自定义程序** | 秒级时间线任意编排手法/力度/速度/部位/加热/气囊/零重力 |
| **一键预设** | 久坐救星、肩颈重点、睡前安神、快速回血、腰部加强、全身舒缓 |
| **摇椅模拟** | 零重力整椅往返（RT7709S 无原生摇椅，详见文档） |

> 支持型号：**RT7709S**（协议可能同样适用于部分荣泰 WiFi 机型，欢迎反馈）。

## 架构

```
┌──────────┐   MQTT 1883(明文)   ┌────────────────────┐
│ 按摩椅   │ ──────────────────▶ │ 路由器（OpenWrt）  │
│ (Wi-Fi)  │   DNAT 劫持到本地   │ 假阿里云 broker    │
└──────────┘                     │ + 8891 控制口      │
      ▲                          └─────────┬──────────┘
      │ 本地 MCU 串口 8899                   │ HTTP
      │ (只读监控)                          │
┌─────┴──────┐                  ┌──────────▼──────────┐
│ 家庭局域网 │                  │ Home Assistant /    │
└────────────┘                  │ CLI / 手机网页      │
                                └─────────────────────┘
```

## 快速开始

### 1. Home Assistant 集成（推荐）

```
HACS → 集成 → 自定义仓库 → 添加本仓库 URL → 安装 rtchair
```

或手动：把 `custom_components/rtchair` 复制到 HA 的 `custom_components/`，重启 HA，
在「设置 → 设备与服务 → 添加集成」里搜 **荣泰按摩椅**，填本地 broker 地址
（默认 `http://192.168.1.1:8891`，改成你路由器 IP）。

> 依赖离线模式已开启（下一步）。

### 2. 离线模式（路由器）

前置：路由器是 OpenWrt/ImmortalWrt，已配置免密 SSH；椅子已连过官方 App 完成配网。

```bash
# 路由器 SSH 别名，按需修改
export ROUTER=router
# 可选：指定椅子 IP（不填则对所有 LAN 设备的 1883 生效）
export CHAIR_IP=192.168.1.100

./tools/offline_on.sh     # 开启离线模式
./tools/offline_off.sh    # 恢复连官方云
```

开启后椅子约 1 分钟内连到路由器上的假 broker。之后：

```bash
cd cli
python3 rtchair.py mode local     # 切到离线模式
python3 rtchair.py status
python3 rtchair.py run programs/久坐救星.plan
python3 rtchair.py serve          # 手机网页控制台 :8770
```

### 3. 命令行工具

```bash
cd cli
python3 rtchair.py --help
python3 rtchair_local.py scan      # 局域网直连 MCU（只读监控）
python3 rtchair_local.py monitor   # 实时看 MCU 帧
```

## 自定义按摩程序

一条 `.plan` 就是一条时间线：

```
00:00  开机
00:05  时长=30 手法=揉捏 力度=3 速度=2 部位=全程 背热=2 气囊=全身 气囊力度=3
06:00  手法=指压 部位=局部 力度=4
12:00  手法=敲击 速度=1 力度=4 气囊力度=4
18:00  手法=揉敲 零重力=开
24:00  手法=揉捏 力度=2 背热=3
```

可操作项见 [docs/属性对照表.md](docs/属性对照表.md)：
手法 6 种、力度 0–5、速度 1–6、部位 3 种、时长 10/20/30、背/腿加热 0–3、
5 个气囊分区 + 气囊力度、零重力、脚底滚轮、姿态微调。

## 兼容性与限制

- RT7709S **没有原生摇椅**（仅 RT7709Pro 等机型有），本项目用零重力往返模拟
- 靠背/腿托/零重力电机**恒速**，协议无速度参数；「更快」只能缩短周期、减小幅度
- 仅支持 2.4G Wi-Fi（模组 HF-LPB130 限制）
- 官方 App 在离线模式下显示设备离线（正常）
- 固件升级请用官方 App，**不建议刷机**（详见 [docs/固件与刷机评估.md](docs/固件与刷机评估.md)）

## 米家 / 小爱同学

米家集成（xiaomi_home）是单向的（米家 → HA），不能反向暴露设备；要让小爱控制，
推荐用**巴法云桥接**：HA 实体 → 巴法云 → 米家「其他平台设备」→ 小爱同学。

步骤见 [docs/小爱同学-米家接入.md](docs/小爱同学-米家接入.md)；
不想用巴法云的话见 [docs/小爱同学-中枢网关方案.md](docs/小爱同学-中枢网关方案.md)（信号设备桥）。

## 安全与隐私

- 假云 broker **无认证**，只应在可信家庭局域网使用，**不要暴露到公网**
- 本仓库不含任何真实账号 token、设备 MAC、云端设备名（已脱敏）
- 自行配置的 token 请放 `~/.config/rtchair/config.json`（脚本会设 600 权限），**不要提交**
- 需要 token 的功能（云端模式）请用官方 App 登录获取，仅供个人设备使用
