# 接入米家 / 小爱同学控制

> 目标：让小爱音箱/小爱同学可以语音控制按摩椅。
> 先说结论：**米家集成（xiaomi_home）是单向的**——只能把米家设备接进 HA，
> 不能把 HA 里的按摩椅反向暴露给米家。要小爱控制，需要走「巴法云」桥接。

---

## 1. 为什么不能直接用米家集成

官方米家集成（`xiaomi_home`）的方向是：

```
米家设备 / 中枢网关  ──▶  Home Assistant
```

它只负责「发现并控制小米设备」，没有「把第三方/HA 设备同步回米家」的接口。
按摩椅不是小米生态设备，米家 App 也无法直接添加它。

所以小爱要控制按摩椅，路线是：

```
小爱同学 ──▶ 米家 App「其他平台设备」──▶ 巴法云 ──▶ Home Assistant ──▶ 按摩椅
```

（巴法云是米家「其他平台设备」里官方支持的一栏，免费够用。）

## 2. 本仓库已经准备好的部分

- `custom_components/bemfa`：巴法云桥接集成（已安装到 HA）
- 7 个语音脚本：6 个一键程序 + 腿部空间最大
  （巴法云会把脚本虚拟成开关，小爱可以“打开/关闭”）

## 3. 你需要做的（约 5 分钟）

### 3.1 注册巴法云

1. 打开 <https://cloud.bemfa.com/>，注册账号（免费）
2. 登录后进入控制台，复制 **私钥**（一串字符）

### 3.2 HA 里添加 Bemfa 集成

1. HA → 设置 → 设备与服务 → **添加集成** → 搜索 **Bemfa**
2. 粘贴巴法云私钥 → 提交
3. 添加成功后，点集成卡片上的 **选项（配置）**
4. 勾选要同步给小爱的实体（建议先只勾这几个，名字简短好念）：
   - `switch.电源`
   - `switch.暂停`
   - `switch.摇椅模式（模拟）`
   - `script.按摩椅-久坐救星` / `肩颈重点` / `睡前安神` / `快速回血` / `腰部加强` / `全身舒缓`
   - `script.按摩椅-腿部空间最大`
5. 提交后，巴法云控制台会看到这些设备/主题

### 3.3 米家 App 绑定巴法云

1. 打开 **米家 App** → 我的 → **其他平台设备**
2. 点 **添加** → 找到 **巴法**（Bemfa）
3. 输入巴法云账号密码
4. 同步完成后，按摩椅相关设备会出现在米家里

### 3.4 小爱同学控制

直接说：

| 你说 | 效果 |
|---|---|
| “打开按摩椅”“关闭按摩椅” | 开关机 |
| “打开摇椅模式” | 零重力快速往返 |
| “打开久坐救星” | 跑 30 分钟预设 |
| “打开肩颈重点”“关闭肩颈重点” | 跑 20 分钟预设 |
| “打开睡前安神”“打开快速回血” | 对应预设 |
| “打开腿部空间最大” | 腿托伸到最大 |

也可以在小米音箱 App 的「训练/自定义指令」里把更自然的话（比如“我要按摩了”）
映射到这些设备动作。

## 4. 注意事项

1. **只能开关类**：巴法云支持开关/灯/风扇/窗帘/空调/传感器；手法的档位（揉捏/指压）、
   力度数值这些没法直接语音，建议用「预设脚本」来覆盖常用组合。
2. **设备名要短**：小爱识别的是米家里的设备名，太长不好念；可以在米家里改名。
3. **免费额度**：巴法云免费版对设备/主题数有限制，够用就好（以官网为准）。
4. **需要外网**：巴法云在云端，家里断网时小爱会控制不了（HA 本地控制不受影响）。
5. 米家 App 的「其他平台设备」入口位置可能随版本变化，找不到就在“添加设备”里搜“巴法”。

## 5. 备选方案

| 方案 | 说明 | 推荐度 |
|---|---|---|
| 巴法云桥接 | 本方案，米家官方支持、免费、无需公网 | ⭐⭐⭐⭐⭐ |
| ha-mi（VRF 模拟） | Go 服务模拟中央空调控制器，让小爱本地发现，配置复杂 | ⭐⭐ |
| 小爱开放平台自定义技能 | 需要公网/内网穿透 + 开发者审核 | ⭐ |
| 只做语音播报 | 小爱播报椅子状态，但不能控制 | ⭐⭐ |
