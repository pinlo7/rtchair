# 小爱同学控制（走米家中枢网关，不用巴法云）

> 实测结论：**米家中枢网关不能直接把 HA 设备注册进米家**。
> 但可以用「信号设备桥」实现无巴法云的小爱语音控制——核心是复用一个米家设备当"信号灯"。

---

## 1. 中枢网关实测（2026-10-28）

| 项目 | 结果 |
|---|---|
| 网关 Web 界面 | `http://192.168.3.239` = **米家自动化极客版** |
| 极客版协议 | WebSocket `/centrallinkws/` + ECJPAKE 6 位验证码认证（**一次性**） |
| 连接测试 | ✅ 用米家中枢的 6 位验证码成功登录（只读） |
| 读到数据 | 设备清单（净化器/摄像机/窗帘电机/多模网关…）+ 自动化规则 |
| 极客版能力 | 规则节点：设备触发/状态、逻辑、变量、定时、延迟、循环、自定义状态、语音播报 |
| **没有的能力** | ❌ 无 HTTP/网络请求动作；❌ 不能创建"第三方设备"；❌ 虚拟设备无法被中枢探测 |

结论：极客版是一个**米家设备内部的规则引擎**，它的动作只能操作米家设备本身，
不能调用局域网里的 HA/按摩椅服务。所以"把按摩椅变成米家设备"这条路走不通。

## 2. 可行方案：信号设备桥

```
小爱同学 ──▶ 小爱训练 / 米家手动场景 ──▶ 一个米家设备（信号设备）
                                              │
                              HA（xiaomi_home，本地经中枢网关读状态）
                                              ▼
                                        按摩椅（rtchair 集成）
```

原理：**用米家设备的状态当"暗号"**。小爱本来就能控制米家设备，HA 又能通过中枢网关
读到这些设备的状态；状态一变，HA 就执行对应的按摩椅动作，然后把信号设备复位。

### 2.1 信号设备怎么选

| 方案 | 设备 | 能编码几条指令 | 说明 |
|---|---|---|---|
| **A（推荐）** | 一只**可调光的米家灯泡**（专用，约 30 元） | 按亮度编码，**理论 100 条** | 小爱说"打开肩颈模式"→ 场景把灯亮度设 30% → HA 执行；执行后关灯。灯放角落/柜子里不影响生活 |
| B（零成本） | 现有「橱柜消毒灯」插座 | 2 条（开=开机 / 关=关机） | 灯会亮，且正常开关灯会误触发按摩椅 |
| C（零成本） | 现有灯带/筒灯某一路 | 2 条 | 餐厅灯会亮，不推荐 |
| D | 专用米家智能插座（约 20 元） | 1 条 | 最便宜的"单指令牌" |

> 想一条语音对应多个程序，选 A；只想开关机，选 D；先跑通流程，选 B。

### 2.2 HA 侧示例（以可调光灯泡 `light.massage_signal` 为例）

把下面放进 `packages/rtchair_signal.yaml`（没有 packages 就合并进 `automations.yaml`）：

```yaml
# 亮度 -> 指令映射
# 10% 久坐救星 / 20% 肩颈重点 / 30% 睡前安神 / 40% 快速回血
# 50% 腰部加强 / 60% 全身舒缓 / 90% 摇椅模式开 / 95% 摇椅模式关
automation:
  - alias: 按摩椅-语音信号灯
    trigger:
      - platform: numeric_state
        entity_id: light.massage_signal
        attribute: brightness
        above: 1
    action:
      - choose:
          - conditions: "{{ trigger.to_state.attributes.brightness < 40 }}"
            sequence:
              - service: script.rtchair_jiuzuo_jiuxing
          - conditions: "{{ trigger.to_state.attributes.brightness < 70 }}"
            sequence:
              - service: script.rtchair_jianjing
          - conditions: "{{ trigger.to_state.attributes.brightness < 110 }}"
            sequence:
              - service: script.rtchair_shuiqian
          - conditions: "{{ trigger.to_state.attributes.brightness < 150 }}"
            sequence:
              - service: script.rtchair_kuaisu
          - conditions: "{{ trigger.to_state.attributes.brightness < 190 }}"
            sequence:
              - service: script.rtchair_yaobu
          - conditions: "{{ trigger.to_state.attributes.brightness < 230 }}"
            sequence:
              - service: script.rtchair_quanshen
          - conditions: "{{ trigger.to_state.attributes.brightness >= 230 }}"
            sequence:
              - service: switch.turn_on
                target:
                  entity_id: switch.rong_tai_an_mo_yi_yao_yi_mo_shi_mo_ni
        default: []
      - service: light.turn_off
        target:
          entity_id: light.massage_signal
```

### 2.3 米家 / 小爱侧配置

1. **米家 App → 智能 → 手动场景**，为每个命令建一个场景：
   - 场景名：`按摩椅-肩颈重点`
   - 动作：`信号灯` → 打开 → 亮度 20%
2. **小米音箱 App → 训练**（或小爱同学 App → 训练计划）：
   - 添加自定义指令：说「打开肩颈重点」→ 执行场景 `按摩椅-肩颈重点`
3. 对每个命令重复（开机/关机用"信号插座"或亮度档位）

完成后：
- 说「打开按摩椅」→ 场景 → 信号灯亮 → HA 执行 → 灯灭
- 状态变化很快（1~2 秒），且**不用任何第三方云**

## 3. 备选：小爱开放平台自定义技能

如果不想加任何设备：
- 小爱开放平台（小米 AI 开放平台）创建技能 → 配置 HTTPS 服务 → 服务端调 HA
- 需要：小米开发者账号 + 公网 HTTPS（你已有 `www.lxcyzl.cn`）+ 技能审核
- 优点：语音直接命中自定义 intent，无需训练；缺点：流程长、需公网

## 4. 注意

- 极客版验证码是**一次性**的，登录后失效；如需再操作网关要重新从米家 App 获取
- 信号设备方案依赖 `xiaomi_home` 集成本地控制正常（中枢网关在线）
- HA 里执行后把信号设备复位，避免状态卡住导致下次触发不到
