# RT7709S 属性 / 取值速查表

来源：APK `assets/config/RT7709S.json` + 云端 `QueryDevicePropertyStatus` 实测（2026-10-28）。
下发方式：`python3 rtchair.py set 属性=值`，或写进 `.plan` 时间线。

## 只读状态

| 属性 | 含义 | 说明 |
|---|---|---|
| `ChairStatus` | 按摩椅状态 | 0 关机 / 1 工作复位 / 2 待机 / 3 运行中 |
| `ProgramAuto` | 当前自动程序 | 0/254 表示手动模式，16–27 对应 12 个官方程序 |
| `ChairRunTime` | 已运行时长 | 秒 |
| `ModuleVersion` | 模组固件版本 | JSON，实测 controller 18.28 / main 1.15 / UI 5.19 |
| `ModuleRSSI` / `ModuleIP` | Wi-Fi 信号 / 公网 IP | — |
| `ProgramCustom` / `ProgramSpecial` | 定制/特色按摩 | 当前 RT7709S 无写入通道，仅回读 |

| 值 | 名称 | 说明 |
|---|---|---|
| 16 | 椅上瑜伽 | 按摩椅上也能做瑜伽 |
| 17 | 脑力唤醒 | 穴位疗法，健脑益智 |
| 18 | 放松冥想 | 是冥想，不是入睡 |
| 19 | 总裁尊享 | 力道适中，深层放松 |
| 20 | 女王尊享 | 温柔轻抚，缓解压力 |
| 21 | 乐龄尊享 | 适合老人，腰臀重点 |
| 22 | 颈肩舒缓 | 舒缓颈肩不适 |
| 23 | 脊背呵护 | 轻柔抚摸，背脊修护 |
| 24 | 腰臀运动 | 气囊按摩腰臀 |
| 25 | 清晨活力 | 晨间按摩，唤醒身体 |
| 26 | 午间小憩 | 午间按摩，促进消化 |
| 27 | 良宵甜梦 | 晚间按摩，舒缓助眠 |

## 限制

- 时长只有 10 / 20 / 30 分钟三档，椅子固件限制
- 下发任意手动属性后 `ProgramAuto` 会变成 254（手动模式）
- 属性值越界通常被椅子忽略，不报错；请只使用上表取值
- 云端接口需要 `token` 头，token 过期需重新 `setup`
