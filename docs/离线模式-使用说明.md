# 离线模式：彻底摆脱荣泰云

> 状态：**已打通并实测**。按摩椅现在连的是你家路由器上的「假阿里云」，
> 控制指令全部在局域网内完成，断网也能用。

---

## 1. 原理

逆向后发现：RT7709S 的 Wi-Fi 模组连的是**阿里云 IoT 的 MQTT（1883 明文）**，
云端下发控制就是往一个 topic 发一条 JSON：

```
topic:   /sys/<PRODUCT_KEY>/<DEVICE_NAME>/thing/service/property/set
payload: {"method":"thing.service.property.set","id":"<数字>",
          "params":{"ChairSwitch":1},"version":"1.0.0"}
```

所以离线方案是：**在路由器上跑一个极简 MQTT broker 冒充阿里云**，
再用一条防火墙规则把椅子的 1883 流量全部劫持到本地 broker：

```
按摩椅 ──TCP 1883──▶ 路由器 DNAT ──▶ 本地 broker（假阿里云）
                                        ▲
                                   HTTP 控制口 8891
                                        ▲
                              电脑/手机上的 rtchair
```

- 路由器上：`/root/local_cloud_broker.py` + procd 服务 `rtchair-broker`（开机自启）
- 防火墙：uci 持久化规则（DNAT + 放行），路由器重启也不丢
- 电脑上：`rtchair.py` 切到 `local` 模式，走 `http://192.168.1.1:8891`

不需要互联网、不需要荣泰账号、不需要 token。

## 2. 一次性准备

路由器（ImmortalWrt）开好 SSH 免密登录，电脑上能直接 `ssh ImmortalWrt` 即可
（已经配好了）。

## 3. 开启 / 关闭

```bash
cd /mnt/nas/ai-coding-projects-nas/rongtai

./tools/offline_on.sh     # 开启离线模式（上传 broker + 启服务 + 写防火墙规则）
./tools/offline_off.sh    # 关闭，恢复连荣泰云
```

开启后椅子约 1 分钟内会连到本地 broker；**如果超过 1 分钟没连上，
把椅子电源拔插一次**（模组是常供电的，必须断电重启）。

## 4. 日常使用

```bash
cd cli
python3 rtchair.py mode local          # 切到离线（只需一次，会记住）
python3 rtchair.py status             # 读实时状态
python3 rtchair.py on / off           # 开关机
python3 rtchair.py set 手法=指压 力度=4 部位=局部
python3 rtchair.py run programs/久坐救星.plan
python3 rtchair.py serve              # 手机网页控制台（离线版一样能用）
```

切回云端：`python3 rtchair.py mode cloud`（配合 `./tools/offline_off.sh`）。

## 6. 注意

1. **官方 App 会显示设备离线** —— 因为椅子连的是假云，这是正常现象。
2. **固件升级不可用**（ServiceUpgrade 是空的）；需要升级时先 `offline_off.sh`。
3. **不用外网也能控制**；但如果路由器重启，broker 服务会自动起来，椅子会在 1 分钟内重连。
4. broker 的控制口 `8891` 对局域网开放，同一 Wi-Fi 下任何设备都能控制按摩椅
   （家里用没问题，公共网络别开离线模式）。
5. 若椅子长时间不连 broker：拔插一次椅子电源即可（模组常供电，软重启不行）。
6. 路由器上的改动都可逆：`offline_off.sh` 会删掉服务自启和防火墙规则；
   服务文件在 `/root/local_cloud_broker.py`、`/etc/init.d/rtchair-broker`。

## 7. 排障

```bash
# 看 broker 日志（路由器上）
ssh ImmortalWrt "tail -30 /tmp/local_cloud_broker.log"

# 看服务状态
ssh ImmortalWrt "/etc/init.d/rtchair-broker status"

# 看控制接口
curl -s http://192.168.1.1:8891/status

# 看防火墙规则
ssh ImmortalWrt "nft list ruleset | grep -A2 1883"
```

常见现象：

| 现象 | 处理 |
|---|---|
| `connected: false` | 等 1 分钟；不行就拔插椅子电源 |
| `连不上本地 broker` | 确认 `offline_on.sh` 跑过、`curl http://192.168.1.1:8891/status` 有返回 |
| 椅子动了但状态不更新 | 椅子只在状态变化/定时时才上报，等几秒再查 |
| 想回云端 | `./tools/offline_off.sh` + `python3 rtchair.py mode cloud` |
